# Two-pass scientific/code audit — 2026-08-21

This audit was performed before spending the multi-node GPU budget.

## Pass 1: forward audit

Fixed:

1. **Sentence-side holdout leakage** -> deterministic **parallel-pair-level holdout**.
2. **Subword over-remapping** -> tokenizer offset-based **exact standalone lexical masks**; split remaps only masked occurrences.
3. **Training-time ambiguity** -> explicit optimizer `max_updates` and manual accumulation.
4. **Unequal language/context weighting** -> contexts averaged within word×seed×language, then EN/DE equal-weighted.
5. **Seed uncertainty** -> **crossed lexical-item × seed bootstrap**.
6. **Slurm assumption** -> removed; scientific runs are single-GPU independent jobs on confirmed-idle GPUs only.

## Pass 2: reverse audit

Further causal confounds fixed:

1. **Alias initialization confound** -> alias rows copied from base rows in both conditions; paired seeds are tensor-identical at update 0; full initialization SHA256 recorded.
2. **Output-class artifact in form predictability** -> primary `surface_nll` uses `P(base)+P(alias)` in both conditions. `lexical_nll` is diagnostic.
3. **Global optimization drift** -> `pre_nll` negative control plus localized `local_surface` / `local_post`; PASS still requires raw directions too.
4. **Path data mismatch** -> independent deterministic EN/DE RNG streams so curricula consume the same language-specific sample sequences, only reordered.
5. **Path LR confound** -> sequential curricula require constant LR.
6. **Adam-history confound** -> optimizer resets when the identical balanced tail starts.
7. **Generic order effect vs lexical-sharing order effect** -> Gate 3 reports shared/split order effects separately and their interaction.
8. **Hardware/code mismatch** -> Gate 1 cannot PASS if paired runs mismatch init fingerprint, effective batch, GPU model, git commit, data schema, or final update.
