# 领域画像：共享语言模型中的词义知识、选择、使用与表达

日期：2026-10-13。本文是跨论文的综合推理；具体实验事实应回到 [论文索引](PAPERS_INDEX.md) 的原文与笔记。**INFERENCE 表示我们对文献关系的重建，不是作者自述。**

最新[第四轮](notes/ROMANCE_SCOPE_CYCLE_RESULTS_2026-10-13.md)把词义、人物指称与命题意义分开，并在新词族上检验目标范围。组合意义可正确表达，而词级判断仍采用完整谓词，这要求区分语义单位选择与知识覆盖。否定是否应影响gold取决于任务，见[ACL2022](papers/hossain-2022-negation-nlu.md)；正确方向的敏感性与最终选择也不同，见[2026否定机制定向阅读](papers/zhou-2026-negation-mechanisms.md)。本地尚未完成内部干预，不能借已有机制解释这些行为。

本轮实证更新：两模型复核已有Type-1成绩，但原PPL错误与稳定chat成功可同时存在；不提供源句也能大量选中参考译文；新应用题遮词仍可全对。因此，知识访问、意义依赖、目标语言表达必须分别检验，不能靠任务名称代替识别。中文補修/冷气等的共有义也使整词Type-1分类不足以指定新语境的唯一gold。见[研究更新](notes/LOCAL_RESEARCH_UPDATE_2026-10-13.md)。

研究尺度对齐ACL/EMNLP/NAACL主会；其他工作可提供素材，不构成探索上限。Dumas/Wang值得迁移的是概念—输出语言组合、关系—内容分解及竞争实验，不能因主会身份就接受所有自然机制/泛化推断。见[定向补读](notes/MAIN_VENUE_COMPARISON_2026-10-13.md)。

## 1. 从综述定位，而不是把词汇现象孤立起来

两篇多语言 LLM 综述分别以语料—对齐—偏差，以及多语言预训练/继续训练—推理策略—评测为主轴。它们提示，语言表现差可能来自语料覆盖、词表/分词、表示共享、任务适配和测量，不可预设全部由一个“语言模块”控制。见 [综述笔记](papers/surveys-2024-multilingual-landscape.md)。这些综述是历史地图，不能拿其闭源模型数据比例或2024模型名单当2026现状。

本项目只取其中一个具体窗口：**模型对语言特定词义的可用知识，如何在局部语境中变成决策和输出**。相比通用多语言榜单，这个窗口能用同一词/不同语境/不同任务构造解释性对照；相比研究某个字形细节，它又指向更一般的知识使用问题。

## 2. 五条文献谱系各自回答了什么

| 谱系 | 核心代表 | 已解释的层面 | 不能直接推出 |
|---|---|---|---|
| 形式共享与迁移 | Conneau、Kallini、Škrjanec、Winther | 共享词汇、累积频次、全局迁移与词形预测之间的关系 | 某次上下文真正用了哪个义项 |
| 同形/形近词语义诊断 | Stingray、Tanwar、Doppelganger、Abuín、SemCog、Uban | 使用错误、语言方向、语境限制、部分/全部语义分化和输出复制 | 所有错误都源于同一参数行或内部竞争 |
| 表征可辨别性与学习过程 | de Seyssel ABX、Inaba SAE | 哪些语言/意义信息可被区分，如何随层/训练发展 | 信息必然被当前解码使用；一个latent等于唯一概念 |
| 因果访问与表达 | Dumas、Körner、Ravisankar、Wang、Sun | 受控改变概念、语言/任务表示或知识访问能影响结果 | “知道却不用”是尚无人研究的新发现，或干预即自然机制 |
| 任务决定与测量 | BIA+、Dijkstra2015、Biloushchenko2026、PriDe、Ok&Lee、patching方法学 | 任务/语言来源/答案格式/干预设计改变可见结果 | 模型和人类具有同构识别系统；所有分数变化是语义变化 |

人类 garden-path/Good-Enough 工作研究不完整重分析；它是可借鉴的理论和设计，不是本项目必须回到的旧“迟到证据”故事。

## 3. 三个不能当作矛盾的组合

**共享提高迁移，同时词义任务有错**：全局均分与少量局部错误可以并存，不构成反例；必须在相同模型/对象上明确总量与局部机制如何联系。

**词形 surprisal 降低，同时理解可能更差**：预测字串不是推断其指称。该区分是测量地基；单独再画两个指标并列图，不足以成为贡献。

**表示可解码，同时生成错**：表示、读出任务与产生答案的计算不是同一对象。Wang的事实输出失败、Sun的多跳访问失误、Dumas的概念/语言干预已提供近邻解释，我们不能忽略它们再宣布“首次发现知识与使用分离”。

## 4. 什么仍可能产生有价值的新认识

一个可行的增量是：在**同一批可检查的语言特定意义**上，同时考查可访问性、语境语义后果与最终表达，然后用少量反事实把失败分解为覆盖不足、条件选择/使用和表达。不是只罗列错误种类，而是**预测哪个任务/语境/语言条件会触发哪类差距**。

另一个有价值结果可以是共同结构：原先看似不同的 cross-language、ordinary polysemy、translation-copy 现象，哪些被一个简单过程解释，哪些必须额外机制？若同语言对照也表现同样机制，并不使研究无效；它可能提升解释范围。需要避免把抽象模型拟合成功误当自然网络实现证明。

没有足够证据时，候选问题也可以终止。当前没有新机制已被证实。我们的门槛不是“零先例”，而是**有能让解释改变的实验，并且最可靠结论成立后值得同行关心**。

## 5. 本轮新增阅读改变了哪些判断

**BIA+ 原文**不是“先识别语言，再禁止其他词义”的简单门控模型。语言成员信息可能在词汇选择之后才足够清晰；非语言任务语境与语言性句子语境影响的层面也不同。这直接提醒：Q1报告语言与Q2报告词义相关，不能推断 Q1 对应内部因果开关。见 [原文理论卡](theories/BIA_PLUS.md)。

**ABX**给出不依赖训练探针的语言/意义辨别测试，并检查与下游任务是否关联；意义辨别指标并不普遍预测 NLI。因此漂亮的表征指标仍需行为验证。**Inaba**把静态双语共享问题转成学习阶段/特征粒度问题，但混合语言激活比例不能直接确定具体同形词的语义决策。

**Goworek & Dubossarsky**把多语言 sense-aware 微调收益分解到数据量、目标语言暴露和词义监督。它示范：负面或更简单解释，可以通过精确控制改变既有研究选择；不必另做大幅提分方法。

**Task Operators（NeurIPS2026目录已核对）**从固定加法向量的不足发展输入相关仿射操作。值得学的是把“哪些函数固定向量表达不了”转成明确预测；不值得模仿的是不经需求分析就给我们模型插一个算子。其局部注意分解恒等式也不能被扩大为从真实zero-shot到ICL整体计算的严格等价。

## 6. 优先阅读路径

准备行为实验：综述 → Tanwar/Doppelganger/Abuín → Uban词义层级 → PriDe/任务测量。

准备机制实验：Dumas/Körner/Ravisankar → Wang/Sun访问与表达 → ABX/Inaba测量 → patching方法学；再决定是否需要TVS/算子或SAE。

准备判断 idea 质量：Cho → Task Operators → ABX → Goworek → Ok&Lee。每篇问“最小前进一步是什么，实验排除了什么，而不是用了多复杂工具”。不要因为某论文未读完附录，就把所有其他有价值的探索一起冻结。

## 7. 第三轮实测后的边界更新（2026-10-13）

[第二轮](notes/OUTPUT_LANGUAGE_CYCLE_RESULTS_2026-10-13.md)没有在两个强Qwen上支持清晰短语境的输出语言干扰；[第三轮](notes/AM2ICO_CYCLE_RESULTS_2026-10-13.md)转到真实文本中的目标关系。低关系分数不能统一归因于词义未访问：源标签粒度、目标指定、问题极性和局部释义错误都参与。解释里出现正确概念还不足以排除关系标准变化或首答后的合理化。
