# 独立自由翻译的探索性 Agent 评读

2026-10-13。**这是单一 Agent 的探索性评读，不是人类 gold、独立双人审核或确证统计。** 两模型并排、身份可见，未采用盲评；没有读取选择题分数来决定标签。审核完整的 24 个预选词族 × 两方向 × 两模型，共 96 条 `task=translation` 输出，未删任何失败或截断。

逐例资产：[Llama review](../../evidence/2026-10-13-local-cycle/2026-10-13-doppelganger-llama8b/translation_agent_review.jsonl)、[Qwen review](../../evidence/2026-10-13-local-cycle/2026-10-13-doppelganger-qwen14b-v2/translation_agent_review.jsonl)。每例记录原始文件/输出/源句/key 的 SHA256、item_id、模型 revision、方向、评语和标签；不在评读文件重复完整源句或生成文本。对应evidence目录保存生成输出，完整原始输入在本地 `generation_file` 指向的run按 `item_id` 重建。

## 1. 评读定义和限制

`output_language` 独立于语义：requested / wrong / mixed / unclear。繁简中文均视为中文；嵌入明确中文短语的日语译文标 mixed。

`sense_status` 只评**目标词义是否在输出中得到表达**，不等于整句翻译正确，更不是内部表征。preserved 允许自然改写；wrong_sense 要有可指认的不同意义或词汇使用；丢失词义、源材料或参考含糊时标 uncertain。错误语言输出仍可保留原来的目标词义，因此不自动记为 wrong_sense。

`other_error` 保存最突出的额外错误（none / omission / addition / referent / grammar / unclear）；短理由可列其他问题。none 不代表专业翻译无瑕，只表示本轮没有单独标出实质错误。模态、语气和自然度的细小差异不是系统穷尽量表。

公开 correct 仅为参考，不是唯一译法。`source_or_reference_ambiguity=true` 的六个方向实例（两模型相同）全部保守标 uncertain：JP→ZH 药罐；ZH→JP 菓子、愛人、薬缶、府内、日系。这是看过本轮材料后的局部审核判断，不改原标签，也不把这些行从原任务复核删除。

`copy_exact_source_key` 是原始 dataset key 的**精确子串匹配**，未做简繁、异体或词边界归一化。部分 key 本来就不是源句的字面形式，故同时存 `source_key_literal_in_source_sentence`。这一指标只识别字串出现，既不能证明真正的复制计算，也不是语义判据。`copy_harm` 由语义评读另判为 harmless / harmful / unknown / not_present；harmful 只指该字串在此输出里的词汇用法有害，不能识别因果机制。

## 2. 本批描述性计数（OBSERVATION / Agent judgment）

这些数字用于整理错误来源，**不报告单一翻译准确率，不作显著性检验**；方向与模型共享词族，不能视为 96 个独立词汇样本。

| 模型 / 方向 | 输出 requested / wrong / mixed | focal sense preserved / wrong / uncertain | 达生成上限 |
|---|---|---|---|
| Llama 8B，JP→ZH，24条 | 18 / 6 / 0 | 18 / 4 / 2 | 1 |
| Llama 8B，ZH→JP，24条 | 24 / 0 / 0 | 14 / 2 / 8 | 0 |
| Qwen 14B，JP→ZH，24条 | 24 / 0 / 0 | 22 / 0 / 2 | 0 |
| Qwen 14B，ZH→JP，24条 | 21 / 0 / 3 | 17 / 0 / 7 | 1 |

Llama 的 6 条错语言输出全部发生于 JP→ZH：认识、爱人、执着、怠慢、打算、洁白。另一个 JP→ZH 他家例子生成重复片段并达到上限；其片段表达别人家的意思，但没有完成尊重规则这一翻译。这 7 条首先暴露输出语言/生成质量，不能统一解释为目标意义没有进入计算。

Llama 共 32 条被评为 focal sense preserved，其中 **11 条仍有错误语言、另类翻译问题或截断标记**。其被标出的具体非义项错误（omission/addition/referent/grammar）共 19 条，Qwen 为 8 条；这是本轮读者的分类计数，允许与错义和语言问题重叠。它说明局部词义保存与整体翻译质量须分开，不能把它们压成一个分数。

Qwen 的 3 条 mixed 为 ZH→JP 线路、一团、外壁：线路保留电路义但夹入中文时长；外壁保留外侧义但有中文纠正说明和杯/水筒指称偏差；一团在中日英混合、自我修订中截断，词义实现不稳定。Qwen 本次无被保守确定为 wrong_sense 的例子，仍有 9 条 uncertain；这不等于证明全部词义正确或能力无问题。

**对表面 knowledge–use gap 的限定（INFERENCE）**：仅凭这 48 条翻译不能算出“差距多少百分比由输出语言造成”，因为尚未将同词的独立访问证据与这里的失败作预先定义的配对归因。本评读能确定的是：语言错误、重复、遗漏、额外情节和指称偏差已实际出现，且有些与目标词义保留同时存在。后续报告应先分列这些可见因素，再讨论剩余词义差异；它们不是模型内部瓶颈的因果比例估计。

## 3. 复制不能代替错义判断

精确 key 命中：Llama 9 条（5 harmless、2 harmful、2 unknown），Qwen 8 条（5 harmless、3 unknown）。Llama 命中的 4 条、Qwen 命中的 4 条，其 key **甚至不字面存在于源句**，说明这个 benchmark key 匹配指标不能直接命名成“原字符复制率”。

**線路是重要反例。** Llama ZH→JP 的线路例子在日语中出现同形 key，不能只因这一点宣布错把电线当铁路。小学馆《デジタル大辞泉》收录「線路」的送电/电信导线及相关设施义；本例因此保守评为词义 preserved，另记时间表达的语法问题。该词典条目只证明相关义存在，不保证所有含線路的语境都无歧义，也不是对此新上下文的独立人类认证。[词典原条目，Kotobank 收录](https://kotobank.jp/word/%E7%B7%9A%E8%B7%AF-551551)

同样，JP→ZH 的认识问题、线路到车站、府内在大阪府修饰下，原字串可与语境吻合；ZH→JP 的執着也可表达坚持不放弃。源数据的 Type-1/同形分类不足以自动支持我们更强的“该字串在当前语言只能表达错误意义”主张。

**補修需把文本问题与内部意义分开。** Llama 将重修课程表达为日语補修，这个词的通常词典义是修理损坏部分，故本评读记录 wrong_sense/有害词汇用法；但它与日语補習同音，仍可能是字形输出错误，不能据该句判断模型实际上想让人修理课程。[小学馆词典条目](https://kotobank.jp/word/%E8%A3%9C%E4%BF%AE-629997)

**药罐/薬缶没有被强判。** 日本汉字能力检定协会的漢字ペディア将薬缶释为带壶嘴的烧水容器，并给出煎药的词源。词源和物品用途重叠提示不能把烧水/煎药视为两个完全互斥物体；本批源句和参考的容器名也需要进一步局部审核。[漢字ペディア](https://www.kanjipedia.jp/kotoba/0006806400)
