# 以主会论文的实验推理为参照：从读出差异到词义使用条件

2026-10-13。用户将 ACL / EMNLP / NAACL 主会作为研究质量和完成度的重要参照；本次选择直接邻近的 **P015 Dumas 与 P044 Wang，两篇 ACL 2025 主会长文**回原文补读。venue 已由正式条目核实，但不代替对测量、干预和泛化逐项判断。本笔记不提出新的 GPU 作业，也不改已冻结题目。

## 2. Dumas：真正有信息量的是反事实结果组合

**FACT / 本次核验**：作者分别追踪“source/target 概念 × source/target 输出语言”的四类结果。§4 在最后提示 token 单层替换，§5 改成被翻译概念词的末 token，并从指定层起持续替换到后续层；又比较单语言 donor 与同概念多语言均值。§6 将翻译表示放入定义任务，并比较直接 prompting、word patching、repeat word 等；主评估包含定义的句向量相似度。§3 单词翻译指标累计可接受词的起始 token 概率。[原文 §§3–6](https://aclanthology.org/2025.acl-long.1536.pdf)

**逆向实验链（INFERENCE）**：

| 已有观察后的缺口 | 仍合理的竞争解释 | 为什么下一实验值得做 |
|---|---|---|
| 某层替换改变输出语言而概念不变 | D1 概念/语言有可分别利用的成分；D2 接收方又从别处读取概念，而 donor 只覆盖任务信息 | 分别追踪四种概念—语言组合；只看总正确率会把两类效果混掉 |
| 概念位置 patch 能用目标语言输出 donor 概念 | D1 共享概念；D2 模型对每种输入语言有独立但可路由的翻译路径 | 对同概念跨语言平均，询问接收方能否使用这个组合表示 |
| 均值表示仍能翻译 | D1 有跨语言通用成分；D3 均值只是压低噪声或保留多个纠缠表示的可读共同部分 | 换成定义等不同读出，并与直接给词、原任务提示比较，检查效果是否超出某个首 token |

这条链的可迁移之处是**先列出干预可能产生的不同输出组合，再选择能区分它们的 donor / receiver**。不能照搬的强推断有三点。

第一，两个 patch 的位置和持续范围不同。持续重写概念位置可能阻止模型后续恢复原信息；它的成功不能和最后提示 token 单层替换共用同一“概念出现于第几层”的解释。第二，均值可用削弱一种会被平均彻底破坏的严格语言专属模型，但不能逻辑排除所有纠缠/混合表示；平滑解码器也可能容忍均值。第三，首 token 质量和定义 embedding 相似度都可能对细粒度竞争义不够敏感。例如“有能力”与“有洞察力”很接近，却未必完成我们的词义任务。这些是本项目的解释约束，不是认定原实验无效。

**Nearest distance**：本项目已没有“首次分开概念和输出语言”的位置。Dumas 主要使同一个概念跨语言迁移；我们的潜在距离在于**同一字形的不同语言义项，在给定语境中怎样被选取并支持新的命题**。若只将 BOOK 换成几个 false friends 再画 patch 曲线，增量很小。

## 3. Wang：失败轨迹能提出位置假说，不能单独确认故障部件

**FACT / 本次核验**：§5.3 比较同关系同对象、同关系不同对象、不同关系不同对象的跨语相似度。§6 对最终错误答案追踪其层间 rank。§7/A.3 的 shortcut 用正确样本的平均 Jacobian 与偏置估计逐语言线性映射；按语言搜索层、缩放和样本数，§7.2 在 all KLAR samples 评估。结果包含英语自身改善。[原文 §§5–7 与 A.3](https://aclanthology.org/2025.acl-long.253.pdf)

**逆向实验链（INFERENCE）**：

| 前一实验还解释不了什么 | 竞争解释 | 对后续实验的作用 |
|---|---|---|
| 不同语言中层相似度较高 | W1 共享答案内容；W2 共享关系/任务模板已足以形成高相似度 | 把关系和对象分别变动，观察哪些相似度来自关系、哪些来自具体答案 |
| 中层正确答案可读，最终答错 | W1 末层表达转换有问题；W2 早期仅存在未被采纳的候选，后续因其他证据/先验选错 | 必须把轨迹当作定位线索，并检查行为任务、相反案例和局部干预 |
| 绕过末层提高答案准确率 | W1 纠正语言映射；W3 广义读出校准/去噪；W4 正确样本选择与选参带来任务适配 | 与同语言、同对象不同关系、不同对象同答案形式及持出任务比较，才能缩小解释 |

这篇的有用设计是**将“任务关系”与“答案对象”拆开**。我们可以迁移到“正在问什么”与“实际使用哪个词义”的区别；不能将所有隐状态差异先称为意义变化。

本次所读正文和 A.3 没有找到明确的独立持出集选参说明，且正文明确评估全体样本。因此现有结果不应被我们直接引用为“未见关系/未见实体的泛化保证”。这不是声称全体增益都来自泄漏；需要代码或作者数据拆分进一步核实。我们若借用该方法，应另行冻结词族、语义题模板和选参集。

英语自身也改善，提醒 W3 并没有被一个跨语总体增益排除。“回答输出语言正确，但换成另一实体”与“直接输出了错误语言”还是两种不同现象。当前 Llama 的六条日语输出不是 Wang 式末层事实替换已在本项目重现的证据。

**Nearest distance**：Wang 已明确研究“中间正确内容没有成为最终答案”和简单绕行修复。我们的潜在增量应是**哪些可观察的语境/任务条件导致语义决策改变，哪些只改变表达可靠性，并能否在未见词上预测二者**。仅展示中层正确义 rank 上升、最后错义胜出，会非常接近它已有的解释尺度。

## 4. 本轮自由翻译结果怎样改变两篇方法的使用次序

**OBSERVATION（来自本地单 Agent 评读，非人类 gold）**：[96 条评读](FREE_TRANSLATION_REVIEW_2026-10-13.md)显示，Llama 的部分失误是错输出语言、重复或一般翻译问题；也有目标词义保留但整句不合格。線路的电线义反例表明“出现同形字”不保证发生语义冲突；日系例子提示参考答案可能改变源命题。少数词的明确词汇问题仍有同音字形/搭配解释。

**INFERENCE**：因此现在最需要 Dumas 的是**概念与语言结果分开记**，最需要 Wang 的是**语义内容与任务信息分开操纵**。还不需要将 Dumas 的均值 patch 或 Wang 的 Jacobian shortcut 变成大规模默认实验。机制方法应服务于一个已经能在行为上区分的预测。

这也意味着应把实验对象从“benchmark 哪个 wrong 选项获胜”提升为一个可审查的关系：给定语言、词形和语境，目标义项应支持什么后续命题。一个完整词族包含至少两个可区别的意义以及各自自然出现的语境；不必要求每个同形词的全部义项互斥，也不必扩建一个新榜单。

## 5. 最小的可迁移设计：语义条件与表达条件交叉

以下为**新实验建议（INFERENCE）**，不追认已发生的实验，不根据现有输出重新写确认题。

固定源句和来源语言，把**输出要求**与**被表达的意义**分开：一组独立调用回答源语言释义/语义后果，另一组表达相同内容但要求另一语言，另有自然翻译。指令语言保持固定，改变“用哪种语言回答”的要求；如果另外改变指令语言，应作为独立因素，不能同时变动后归因给输出语言。短回答与自由输出都保留，把格式失败单列。

再加入少量**目标词替换为局部无歧义表达**的配对：句子主张与后果标签保持，替换只降低词义竞争；替换句需新审核。对照普通单语多义和不冲突词，检验是否只是一般语言能力/任务难度。确认词族和语境模板应在探索前冻结；成功访问子集与全体均报告，避免只挑“看起来知道”的例子。

| 解释 | 对未见词族应作出的不同预测 | 会使它失去吸引力的结果 |
|---|---|---|
| **表达负担**：源意义已正确，指定输出语言/自由生成不稳 | 改输出要求主要改变语言遵循、流畅度和词汇化；独立的语义后果较稳定 | 只改输出要求，也系统地改变已审核后果题中的意义选择，且不能由任务理解解释 |
| **词义选择条件**：语境与语言线索影响当前选义 | 词义冲突项对语境证据有可预测响应；无歧义替换改善后果与表达，且效应能泛化 | 改善只在特定候选措辞出现，或同等幅度存在于无冲突项而简单能力模型已解释 |
| **一般能力 / 简单线索整合** | 同语多义、跨语词义和一般翻译难度遵循共同规律；强模型或明确语境降低错误 | 存在稳定额外交互，能在新词/任务上提升预测，而非事后特例 |

后果题仍可能被常识猜中，因此应检查小批删词/语义替换条件；这些检验服务特定解释，不无限扩张成准入关卡。候选稳定和高 PMA 只约束某些读出问题，不能代替语义特异性。自由输出不强行只认一个参考，也不能只由一个 embedding 分数决定对错。

## 6. 可能超越最近邻的最小贡献是什么

**INFERENCE / 贡献候选，尚未成立**：建立并验证一个跨词族的条件规律，说明何时**输出语言负担只损害表达**，何时**词义竞争已经改变后续语义决定**。在相同源命题上分别检验两类改变，使自然错误与其修复具有不同预测。若普通单语歧义遵循同一规律，仍可能形成比“跨语言有特殊缺陷”更一般的解释。

形成这类贡献至少需要：可复核的自然现象、有效语义测量、能区分上述解释的配对操纵、词族/语境持出预测，以及相反结果的真实保留。这些是从本科学问题推出的证据需求，不是“主会论文都需要更多模块”的格式要求。

如果将来进入机制分析，优先复用四格结果与分解 donor：同意义不同语言、同语言不同意义、相同答案标签而不同语义；记录接收方意义与输出语言分别如何变化。位置/层窗口由行为差异提出，不事后只展示最能修复的位置。修复成功仍只确立受控可用性；若没有必要性或自然轨迹的额外证据，应停止于这个较窄主张。

本轮补读改变的是**增量的目标单位**：从单个 benchmark 分数差，转为可泛化的条件—错误类型关系。两篇 ACL 主会论文提供实验逻辑和强基线，也留下测量与泛化边界；我们应在这些边界上做更可检验的一步，而不是在它们的术语下重新命名少数失败。
