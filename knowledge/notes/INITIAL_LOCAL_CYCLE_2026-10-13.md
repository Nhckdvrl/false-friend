# 首轮本地研究循环：同一词义的访问、语境与表达

2026-10-13；执行前冻结的设计。问题仍是当前主线，不恢复历史 A/B/C。

## 科学问题与独立判断

重要未知：Doppelganger-JC 的低孤立词义分数、较高语境／翻译分数，是否真的意味着目标意义知识不足？原论文 §4.1 的最低困惑度评价与公开代码相符，但代码对**包括问题前缀的整个陈述取 token 平均损失**。这同时改变候选长度、措辞熟悉度与条件关联的权重。知识可访问性不能仅由这个分数定义。

最近邻已经做了三个任务以及同形译文错误分析；重复三个准确率并非贡献。Holtzman 等的 [surface-form competition](https://aclanthology.org/2021.emnlp-main.564/) 已研究字符串概率与概念答案的区别；本轮不宣称首次发现评分偏差，也不预设校准必然正确。

竞争解释：H1 目标语言意义覆盖不足，多个独立读出均失败；H2 原字符串分数主要受候选措辞／长度影响，指令判断或自由解释能访问正确意义；H3 已知意义在语境或翻译中未被正确使用，稳定失败集中在特定任务。三者允许混合存在。

区分观察：原分数与条件分数改变哪些逐词选择？去掉词／语境后还保留多少候选排序？固定候选、轮换位置的指令判断是否支持原错误？自由输出是否实际出现同一误义？反方向结果同样有价值：若全部读出一致失败，先研究覆盖／能力，不谈内部选择瓶颈。

## E1：已发表任务的 Type-1 地基

来源 [作者仓库](https://github.com/0017-alt/Doppelganger-JC)，SHA `eb1c4f3f17403af238046bf218dc49643bc2e2e2`。使用完整 Type-1，两个语言视角各 464 行；语境／翻译 JP→ZH 462、ZH→JP 455。按作者文本、邻接词干扰项、无 chat template、bf16 前向与整段平均 NLL 复核。Llama-3.1-8B-Instruct 使用缓存的 NousResearch 镜像，不能未经权重核验称与原 checkpoint 严格一致；Qwen2.5-14B-Instruct 是独立更强模型复核。

源码 `calc_ppl_meaning.loadQADataset` 省略自身语言的 word 字段，但评分调用请求该字段，会 KeyError。本地**只将自身词形设为字典键**以恢复已发表任务，注明最小修复；不修改原仓库。Type-2 中文语境另有 `keys[:1]`，本轮不使用这支，不能据此判定原论文结果错误。

同一次前向另保存前缀、候选、收尾 token 的 NLL 总和与数量、候选平均／总 NLL。字符到 token 边界由 fast tokenizer offsets 明示；跨边界 token 单独计数。另做不提供词／句的候选先验读出，属于新诊断，不能冒充原分数。不会凭校准后分数宣称潜在意义正确。

## E2 / E3：独立任务读出

E2 在按词族哈希预选的 96 族上使用原候选，分别问明确来源语言的孤立词义、语境意义、翻译，四次循环排列。平均按内容对齐的完整词表 label logp；保留各轮选择、位置不稳定、非选项最高概率 token。来源明确是知识访问条件，不设置不可观察真来源任务。E3 在其中预选 24 族上独立生成释义、语境释义、翻译，greedy，保存完整输出和截断。生成不由本模型自动判为正确；局部研究者审核明确不是额外人类 reviewer。

全体原任务结果和所有相反案例保存；以词族为推断单位，两方向、三任务、轮换不是独立 n。Type-1 全部作为探索地基；Type-2/3/4 不用于本轮形成假设，未来确认仍须冻结词族分组，并检查跨类型别名。

## 材料抽查与预算

在见模型输出前，`random.Random(20261013)` 抽查 JP→ZH 16 个样本：直行、名字、认定、体裁、直直、洋画、葛藤、见地、认识、着实、改装、翻弄、女儿、着想、用意、商谈。认识／名字／女儿等有清楚对比；认定、改装、商谈的 wrong1 可能是有效语义改写或部分重合；见地／着想也需仔细界定“复制就是错”。不改源标签、不排除这些行；将这些疑点另记，原任务成绩称 source-label agreement。

资源实查：本地 4×RTX PRO 6000，约 96GB/卡，均无计算作业；24 CPU，工作盘剩余约31TB。复用 `verl-clean` conda（Python3.12、torch2.8+cu128、transformers4.57.6），sm120 CUDA 实测成功。两模型分别单卡，先约 1.5万候选序列＋2304 label 前向＋144 次生成／模型，预计几十分钟以内；无训练、下载大权重或费用。用户另授权 fvcrc10/11/12/13/15/20/21 SSH，总计最多8张空卡；本轮本地足够。

工程预检发现共享环境存在另一 `scripts` 包，旧测试的 namespace 导入被遮蔽；添加本仓库 `scripts/__init__.py`，不改共享环境。软件测试只检查代码；原任务复核、新观察和因果解释分别报告。
