# 候选评分与语义访问：本轮实验之前的定向阅读

2026-10-13。本笔记写作时**未读取任何本轮模型结果**；不占用 GPU。已读 [首轮冻结设计](INITIAL_LOCAL_CYCLE_2026-10-13.md)、[Doppelganger-JC 笔记](../papers/kitamura-2025-doppelganger-jc.md) 和 [FIELD_GUIDE](../FIELD_GUIDE.md)。以下是文献方法事实与实验推理，不是新观察报告。

## 1. 两篇文献到底改变什么判断

定向来源为 [Holtzman 等，EMNLP 2021](../papers/holtzman-2021-surface-form-competition.md) 和 [Wiegreffe 等，EMNLP 2023](../papers/wiegreffe-2023-answer-choice-probability.md)。两份卡均按 **S2** 登记：已读直接相关定义、实验与限制，不假称穷尽图像、附录或代码复现。正式 venue 和完整作者已核。

**INFERENCE**：我们需要同时允许两个反例：原始候选分数很低，但模型能可靠表达正确意义；候选校准后分数变好，但模型仍不能自主表达或使用该意义。前者反驳“这个分数可直接界定知识不足”，后者反驳“任何提分都在恢复真正的词义知识”。把校准后的方法设为唯一真值会重演原来的测量问题。

## 2. 本轮 E1 的五个分数分别测了什么

下列是我们的推导与操作定义，**不是声称原论文做过本项目实验**。令问题前缀为 x，候选为 y_i，固定收尾字符为 z；其实际 token 分段后的 NLL 和分别为 A、B_i、C_i，计数为 m、n_i、k_i。跨边界 token 必须按代码真实策略记录，不能假设每个字符串边界都是 token 边界。

| 读出 | 形式 / 目标 | 最直接竞争解释 |
|---|---|---|
| 原整段 mean NLL | `(A+B_i+C_i)/(m+n_i+k_i)` | 前缀与候选平均损失的混合权重、收尾与候选交互 |
| candidate sum NLL | `B_i = −log P(y_i | x)` | 具体字符串概率、长度、措辞先验 |
| candidate mean NLL | `B_i/n_i` | 每 token 可预测性；不是候选的总概率 |
| null candidate score | 去词/语境，仅保留明示的任务域后，对同一候选计分 | 源标签与候选先验、null 模板失配 |
| log-ratio 校准 | `log P(y_i|x,d)−log P(y_i|d)` | 输入造成的相对关联增强；不保证概念总概率或自然使用 |

**共同前缀不会自动相消（INFERENCE / 代数）**：比较 total **sum** 时，相同 token 前缀的 A 可消去；比较 total **mean** 时，分母随候选变化，A 的权重也变化。忽略 z 的简式为 `(m μ_prefix+n_i μ_candidate)/(m+n_i)`。即使候选平均损失不变，只改变候选长度，也能向上或向下移动整段分数，方向取决于两段的相对平均损失。故“有语境比孤立词表现好”中可能混有评分结构变化；尚不能据此断言已有结果主要由这个因素导致。

**必须区分校准类型**：对 sum logp 作 null subtraction 与对 mean logp 作 subtraction 不等价。后者仍可作为明确命名的新诊断，但不是原 PMI_DC 的直接实现。null 输入本身保留哪些任务线索必须存档；去词后成绩高可指向候选/标签线索，去词后低则只说明该删减削弱了读出，不能单独证明 lexical sense 被正确使用。

## 3. 逆向恢复实验链，而非只收集评分版本

**INFERENCE**：设冻结模型的失败由三类因素混合造成：H_cov 是目标语言意义不能在可靠条件下访问；H_read 是当前字符串/答案格式歪曲能力估计；H_use 是意义可访问，却未支持当前语境决策或表达。每个实验的价值来自排除不同部分，而不是争夺最高准确率。

| 本轮比较 | 什么结果会削弱一种解释 | 什么结果仍不够 |
|---|---|---|
| 整段 vs candidate sum/mean | 大量逐词翻转集中于长短候选或高前缀损失，削弱整段分数的直接语义读法 | 改分数提分不证明 H_cov 为假 |
| 原输入 vs null | null 保留原排序/成绩，削弱依赖题干的解释 | null 低分不排除模板效应；不能把 null subtraction 当真值 |
| 四循环 chat | 同一内容跨位置稳定地选对，削弱简单固定位置偏置 | 稳定仍可能源自候选辨识、排除法、意义重合或先验 |
| 无候选独立释义 | 精确给出语言特定意义，并排除另一语言误义，直接削弱这些词的纯覆盖解释 | 广泛或含糊定义可能同时包住两个义项 |
| 独立语义后果 / 翻译 | 已可访问同一义项却稳定产生相反语义后果，为 H_use 留下空间 | 翻译表面复制可只发生在表达侧；需另外检验语义使用 |

四次循环将每个内容放到每个位置一次，能抵消一个固定、可加的 label logit 偏置；它不保证移除“此内容×此位置/邻接内容”的交互。保存每轮结果比只保留平均更有解释力。原四选项存在语义重合时，首先保留 source-label agreement，避免把有道理的改写计作确证性词义失败。

E2 还有一个几乎零额外推理成本的机会：使用已保存的完整词表 label logp，逐轮计算 PMA 与候选前两名原始概率差。公式和条件见[2023 方法卡](../papers/wiegreffe-2023-answer-choice-probability.md)。它能排除“未列出的表达拿走概率，足以改变本次排序”这一局部竞争解释；不能排除内容—标签绑定失败，更不证明自然翻译时会用同一意义。

## 4. 什么证据会让我们放弃“知识不足”解释？

以下是**新实验建议与解释标准（INFERENCE）**，不是预设全部必须闯关的流程。只针对产生解释分歧的词族做局部诊断。

1. **先在没有答案提示的独立调用中建立可访问性**：只给词形与明确语言，用短自由释义识别目标义。审核要求能区分具体竞争义；保留错义、模糊、双义和拒答，而非只挑漂亮样例。若使用新措辞/新语境，另做本地材料审核。
2. **检验特异性**：同一词形切换明示语言，应产生相应意义差异；再用不同表达的语义后果题验证。正确解释不能只从后果题的一般常识或备选项猜到。可以用删词/语义替换作为少量反事实，无须先建立庞大全词义分布。
3. **让“知道”与“失败”属于同一对象**：独立释义已正确的词，在另一独立调用中仍错误使用同一语言、同一义项；不得先让模型回答 Q1，再把其答案放进 Q2 后称为自然使用证据。若加入正确释义会修复，只算构造性可用条件。
4. **将探索规律带到未参与选择的词族**：探索发现的阈值与类别先明示，再验证其是否预测新失败。多个 prompt、双语言视角、四次轮换不增加独立词族数。

若这些证据成立，可以放弃“这些词的全部失败只是没有该义知识”这一解释，并限定为**在已测试访问条件下，该知识可用**。不能据此证明每次失败时内部都已经形成正确义项，也不能否定其他词确有覆盖不足。相反，若独立访问和语义后果均失败，应优先回到知识覆盖、材料和能力边界；没有必要保住“知道但不用”叙事。

## 5. 最小非平凡增量与及时退出条件

**INFERENCE**：最近邻已经有三任务对比、字符串/概念区分、先验校准与答案格式效应。仅在 Doppelganger-JC 上重复这些效应，属于必要地基。值得追的增量是：**某类“孤立知识差、语境表现好”的差距中，有多少是读出构造，有多少能跨独立输出/语义后果保持；这个分解能否预测未见词族、任务和语言条件下的失败？**

有价值的简单结论可能是现有分数系统地低估某类知识访问，且已有校准/合适读出足以解释多数差距。要使它超过一般“换个评分会变”的常识，必须量化具体归因、给出可预测条件，并指出它改变了哪条既有科学推断。若只剩少数措辞疑例，或连续读出变化均不改善对语义使用的预测，则结束这一局部校准方向，把资源转回可靠词族的使用/表达问题。
