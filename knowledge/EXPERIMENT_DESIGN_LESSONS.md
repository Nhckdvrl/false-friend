# 从成熟问题中生长新解释：实验设计逆向训练

本文件的推演均为 **INFERENCE**。它重建可能的研究生成路径，不声称知道作者心理。来源入口见 [索引](PAPERS_INDEX.md)。每条由“已有解释 → 认知缺口 → 区分性设计 → 结论上限”组成。

## Cho：先证明某操作能够做，再问模型是否真的这样做

已有 ICL copying/induction 解释很强，但正确标签未出现在 demonstrations 的条件挑战其完整性。低秩过滤器提供构造性可能；自然 few-shot 的几何变化检查类比；相关组件消融提供因果作用；不同任务映射结构提供失败边界。四种证据不是四张重复支持图，而是不同推断层级。

转用于我们：给出正确词义/替换状态能救回答案，只说明外部操作足够，不证明未修改模型原来已经自然调用那个词义。必须与无干预访问证据、选择性扰动和不相关语义不变性一起判断。

## Task Operators：从固定表示的表达限制寻找新变量

已有任务向量把示例效果压成常量；输入相关算法揭示其不足。新工作利用注意分解构造随状态变化的仿射操作，并与固定向量方法和完整 ICL 比较。科学增量不是“又有一个向量”，而是把**常量效应与输入条件效应**分开检验。

转用条件：只有当自然词义使用差距无法由简单常量偏置解释时，才考虑输入相关干预；不能看到算子论文就把研究变成方法移植比赛。

## ABX：把“有信息”变成明确的测量对象

旧跨语言表示工作依赖训练探针，探针本身的拟合能力混进结论。ABX 从语音辨别迁移最小三元组比较，使语言与意义相似性分开；零效应条件和下游相关检查又限制指标含义。

转用：为候选“正确/错误词义表示”定义语义和语言都匹配的三元组；报告它是否预测同一实例的语义行为。若不预测，研究结论应当是指标边界，而不是因为它叫semantic metric就宣布模型懂了。

## Goworek：一次正确的重新控制可以比新架构有价值

已有多语 sense-aware 微调效果可能同时变化训练数量、是否看过目标语言和基座能力。重新对齐暴露与训练量后，原有收益归因变弱。这类论文的科学对象是**谁应对改善负责**，不是只说“方法没用”。

转用：强上下文比弱上下文长、明确language cue也增token、翻译与释义输出不同、筛选“已知词义”只保留容易词，都会把多因素变化误读成单一机制。保留原结果复现，另做说明变量的对照，不偷偷修数据然后说原论文被反驳。

## Wang / Sun：知识存在与访问失败不是空白，下一步必须更精确

两篇分别切入多语言事实输出和多跳访问，给出内部状态与干预。我们不能再以一个“能被patch救活的词”为贡献。应问：当前词义是否有独立可访问证据；为何只在某语境不被用；救援是否直接注入正确答案；哪些反事实能把选择失败和表达失败分开。

## Ok & Lee：不要在排除简单解释前宣布内部瓶颈

先有 prompt component order 的稳定行为差；训练格式与简单忘记选项是合理竞争解释；控制后才测试因果注意位置限制和定向救援。顺序不是论文精彩之处，**每一步让一个仍可能的解释退出**才是。

转用：Q1→Q2自我条件化是我们已经找到的测量路径之一。它只需足量同词和合理任务对照就可评估，不应耗费整个研究周期无限修 prompt。

## 每篇文章的逆向训练卡

第二轮的新教训：请求德语解释后，Llama的自然答案常从`Die richtige Antwort ist A`开始。只比较首token AB，会把39次正确回答记错；错误解释也不能独立证明模型先前自然选了错误义。[第二轮结果](notes/OUTPUT_LANGUAGE_CYCLE_RESULTS_2026-10-13.md)因此关闭局部强干扰猜想。AM2iCo的同文本改目标设计提供另一种依赖检验，但其自动实体标签仍须局部审查，见[第三轮设计](notes/AM2ICO_TARGET_BINDING_DESIGN_2026-10-13.md)。

本地2026-10-13案例：新应用题Qwen原词18/18、遮词也18/18，说明“换成后果题”不自动解决意义依赖的识别。追加自然显式双义最小对，固定问题/选项并要求答案翻转；含糊原词保留null标签，仅报告偏好。这样可以区分固定答案偏好与对具体输入意义的响应，但仍不能直接证明自然双语选义机制。见[本轮更新](notes/LOCAL_RESEARCH_UPDATE_2026-10-13.md)与[v2设计](notes/DOPPELGANGER_ZH_MINIMAL_PAIRS_V2_2026-10-13.md)。

先遮住结果，再填写：前一个实验解决了什么？还存在哪两个机制都能解释？它们在哪个干预下预测不同？如果结果相反，该删哪句主张？这个设计需要哪些真实数据对象？若成功，是否比最近邻多了一条可预测的规律？

最后再对照作者实际结果和局限。不同结果也应产生下一步知识；没有阴性分支的实验通常只是为故事补图。

## 第三轮：相同释义不等于单因素干预

AM2iCo初次加回原文保持了释义字符串，却遗漏了只给释义条件中的显式目标列表。逐例审查发现目标误认后，补做原gloss-only完整提示前只加原文的匹配条件，并另测原文+目标列表。这是纠正自身设计，不是事后选择最优提示。另有same/different都答No、解释随问题改变的实例：极性平均不能替代逐例语义一致性。[设计纠正](notes/AM2ICO_TARGET_RESTATEMENT_DESIGN_2026-10-13.md)与[研究更新](notes/AM2ICO_CYCLE_RESULTS_2026-10-13.md)。

## 第四轮：操纵所问单位，使竞争解释产生相反预测

同一否定句，词级同义关系和完整谓词关系可以有相反gold。只移动target边界、固定句子及问句，比重复改提示更接近“模型到底比较什么”的问题；同时须报告两个gold对象，不能把正确率差叫同一任务修复。[范围设计](notes/SCOPE_FOLLOWUP_2026-10-13.md)与[结果](notes/ROMANCE_SCOPE_CYCLE_RESULTS_2026-10-13.md)保存新族预测及未人审边界。旁例分支中TARGET标签被误当被问单词，说明“独立释义”也需逐例检查对象；用实际词形追加后，原reformado同化例消失，不把它当稳定机制。

[Liu等EMNLP2022](papers/liu-2022-context-word-bias.md)已用删减输入和人类判断讨论词/语境依赖。分别训练的预测器可说明信息充分性，但分数差不直接定位完整模型自然使用什么；同样，本地固定释义的输入对照也不是隐藏状态机制实验。
