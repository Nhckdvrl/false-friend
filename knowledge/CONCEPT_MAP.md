# 主张、对象与解释的交叉地图

完整综述式画像：[FIELD_GUIDE.md](FIELD_GUIDE.md)。实验方法的来源和尺度：[EXPERIMENT_DESIGN_LESSONS.md](EXPERIMENT_DESIGN_LESSONS.md)。下述是综合 **INFERENCE**，不是宣布模型包含若干已识别模块。

| 观察层次 | 原有资产 | 必须补足的推断 |
|---|---|---|
| 字串更可预测/迁移均分改善 | Kallini、Škrjanec、频次/重叠研究 | 不能直接知道当前sense是否被正确使用 |
| 词义或使用判断失败 | Stingray、Tanwar、Doppelganger、Abuín、Uban | 要分开覆盖、上下文、来源约定、输出和任务负担 |
| 语言/意义可被表征距离或SAE分开 | de Seyssel、Inaba | 可辨别/可解码不是自然解码已使用 |
| patch或shortcut改变输出 | Dumas、Körner、Ravisankar、Wang、Sun | 构造性作用不单独证明自然机制或知识原先可访问 |
| 多种回答/提示形式分数不一致 | PriDe、Ok&Lee、现有小试跑 | 排除位置先验、任务/问题难度、生成自我条件化，不自动叫作内部语义竞争 |
| 人类语言/任务条件改变干扰 | BIA+、Dijkstra、Biloushchenko、Good-Enough | 抽象区分可迁移；RT/眼动和Transformer状态并不等价 |

## 需要独立登记的变量

词条与实际屈折字形；exact form与near form；词汇总体义项关系与给定语境sense；句子语言、显式来源、被要求的回答语言；语义内容与答案token；数据暴露/能力与语言特有效应。

原标签无法观察的目标不能被当模型应该预测的事实。反过来，研究在语境中如何使用一个同形词，不一定需要知道它在制作者脑中“属于哪门语言”。

## 真正开放的推断

对同一批语言特定义项，哪些实例属于覆盖不足，哪些在明确条件能被访问但使用受语境/任务影响，哪些只是表达失败？能否用少数可测变量预测新词/新语境的类别与干预响应？若普通单语与跨语共享机制，能否统一此前分散结果，而不是把共同性判为无贡献？

这使知识库服务持续科学判断，而不是保护原来三个故事。每次出现新证据，更新对应边，而非追加互相冲突的命令。
