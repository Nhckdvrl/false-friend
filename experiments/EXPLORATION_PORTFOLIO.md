# 初始高信息量实验组合——允许主动修改，不是固定闯关

目标：围绕**多语言词义知识如何变成语境中的正确使用**发现可靠线索。以下实验不预设顺序、效果方向、最终机制或论文结构。本地 Agent 可在同一科学空间内提出更好的实验；说明依据与变量后执行。

## 公共设计约束

每个测量都绑定 `lexeme_family_id / sense_pair_id / context_family_id / task / model_revision / protocol_revision`。保留全体样本结果和“访问能力通过”子集；后者是条件分析，不可通过只留下成功义项制造knowledge–use gap。探索/确认按词汇家族留出；同词翻译、屈折、同义改写尽量同组，防止泄漏。

原始来源标签可以支持原任务复现。任务适配、纠正语法、重新写语义后果题须另打 revision，不覆盖原样本。机器发现的词形/来源风险不等于原论文全部失效。人工审核聚焦关键类别、随机抽样与疑点，而不是一上来要求大规模全量标注。

初始样本量用可取得的有效词义实例、效果稳定性和预算决定；“先审查10–20个随机条目”是质量检查，不是所有统计研究只用20个词，也不是达不到任意整数就判死。

## P1：原研究复现与材料分层

**问什么**：已有模型错误/方向不对称，在原任务和当前有能力模型上是否能被重现？

**近邻**：Tanwar语言/上下文任务、Doppelganger三任务、Abuín WiC。尽可能用原checkpoint和原评分；不具备则写明独立模型复核，不叫精确复现。

**记录**：原prompt完整文本、生成长度、chat模板、人工分类规则或原似然指标、源数据版本；exact/near form、大小写与词性、语言方向是否可观察、是否故意错误句分层。没有人工oracle时报告原始输出，不伪造准确率。

**解释分叉**：稳定现象→为P2/P3提供对象；只有某协议出现→协议依赖是条件；原材料损坏→保留原复現与修订对照，不能直接把行为反转算机制证据。

## P2：同词义的“可访问—实际使用—表达”矩阵

**竞争**：未学会目标词义；会但当前语境选错；语义使用对而翻译表达错。

**实验**：同一sense pair上独立原语言释义/示例确认、上下文意义判断、至少一种不需要复制原词的指称/性质/事件后果判断、自由翻译或释义。候选比较与生成分别报告；非响应和指令失败独立编码。对部分重叠义、完全分离义、普通同语言歧义及非冲突参照分层。

**为什么信息量高**：总分一样的错误可能落在不同象限。它不是天然的因果分解，但能决定下一次需要改什么：覆盖不足需测试频次/能力；实际使用差距才值得选择性干预；只输出错则与Dumas/Körner/Wang输出路径比较。

**反例**：所有任务不一致仅因难度或表达长度，换独立语义指标消失→矩阵测量需修；并不据此宣布所有词义研究失败。

## P3：独立语义证据、语言信息、任务提示的相互作用

**竞争**：简单熟悉度/证据组合；依赖条件的信息使用；任务/答案路径。

**操纵**：词义与基本命题固定，改变可明确分离的语义约束、句子语言证据、回答语言/任务说明。对实际source语言不可观察的exact form，不设置不可知的“真来源”问答。若操纵迫使无意义code-mix或不合语法，放弃这组因果对照，而非强凑矩阵。

**统计**：先在独立样本估计cue强度或由语言专家盲评，避免用待解释结果同时定义cue强度。对频次/基准能力、主效应模型和适度交互模型做词汇家族留出预测；报告复杂度、校准误差与不确定性。观察交互不等于内部硬门控；无交互不等于没有有价值的简单解释。

**扩展**：先前Q1报告语言可能影响Q2释义，因此Q2-only、Q1-first、Q2-first、externally-fixed-Q1是可选测量路径对照，不是全部项目必须围绕的唯一设计。

## P4：表征与行为联系——只有清楚对象才选工具

**问题**：行为上可访问目标义项，但在某条件使用失败；模型状态中何种变化与这种差距相容？

**工具来源**：de Seyssel ABX避免训练探针容量混入；Inaba的SAE提供语言/语义共现分析；Dumas/Körner/Ravisankar提供因果交换；Wang/Sun是“知识存在 vs 访问/表达”最直接竞争解释。先用最小适配，不同时堆全部工具。

**关键反事实**：保持词形/位置与任务尽量一致，更换语义而非仅答案字符串；同答案标签但不同语义donor、同语义不同语言donor、不同义但同词形donor、双向patch和无关任务控制。加法steering、训练filter/算子只能证明构造性作用，不能单独确认自然算法。

**足够继续的线索**：跨多个独立词义、语义指标与不同donor变体预测一致；下一干预能排除一个明确竞争解释。**不够**：某层相似度高、某个head patch后答案变对、随机donor也能救。

## P5：解释的边界与共同结构

在完全未参与设计的新词/语境族上预测错误类型与干预响应；改变语言能力、partial/total sense overlap、任务表达方式或模型规模中最有解释力的一两个轴。任务/模型数不是越多越好。

若普通单语歧义与多语同形词共享一套预测规律，应问能否统一已有分散结果；若必须额外语言因素，界定其条件和必要性。若改prompt就消失，但分布变化仍能预测错误，也可能是有意义的测量边界。只有“新画了几张图”则不宜作为贡献。

## 每轮保留的最小产物

- `runs/<id>/manifest.json`：来源、代码、模型/分词器版本、原prompt哈希、选样、资源和协议。
- `trials.jsonl`：逐例分数/生成、义项/语境/任务分组、所有错误/非响应；不要只存均值。
- `analysis.md`：空间→线索→主张→贡献；竞争解释、反例、已排除与未排除因素、下一实验为何值钱。
- `knowledge/notes/<decision>.md`：本次结果如何改变文献理解或实验设计，添加原文引用和阅读状态。

对既有小模型试跑，仅保留审计价值，不从其弱表现推断8B/32B模型或整个理论。正式使用的资源与模型由本地 Agent 实查并选择。
